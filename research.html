Potholes Detection using Advanced Object Detection Techniques

90.3% Model Accuracy
2 Model Ensemble
Real-time Detection Speed

Abstract

Developed a real-time pothole detection system using an ensemble of YOLOv8m and MobileNetV2 models, achieving 90.3% accuracy across challenging conditions including low-light, rain, and cluttered environments. Integrated advanced preprocessing techniques (CycleGAN for domain adaptation, CLAHE for contrast enhancement), model optimization, and edge deployment for scalable smart road monitoring.
